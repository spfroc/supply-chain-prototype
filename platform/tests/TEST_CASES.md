## 2. Web 与 H5 共用业务

| 编号 | 模块 | 测试场景 | 预期结果 |
|---|---|---|---|
| CLI-001 | 商品 | 查询企业协议商品 | 返回市场价、会员价、协议价和可售库存 |
| CLI-002 | 商品 | 点击商品进入详情 | 展示商品编码、价格、库存和服务说明 |
| CLI-003 | 购物车 | 首次加入商品 | 新增购物车记录 |
| CLI-004 | 购物车 | 重复加入相同 SKU | 合并数量，不生成重复行 |

| CLI-007 | 购物车 | 数量超过库存 | 返回 400 并提示库存不足 |
| CLI-008 | 购物车 | 切换选中状态 | 选中状态持久化 |
| CLI-009 | 购物车 | 删除商品 | 删除成功 |
| CLI-010 | 结算 | 未选择商品结算 | 返回 400，不生成订单 |

| CLI-013 | 结算 | 无有效协议 | 返回 400，不允许下单 |
| CLI-014 | 订单 | 查询订单列表 | 按时间倒序返回金额、商品数量和状态 |

| CLI-018 | 响应式 | 375px 宽度访问 H5 | 内容无横向溢出，底部导航可用 |
| CLI-019 | 响应式 | 390px、430px、520px 访问 H5 | 卡片、按钮和弹窗均在视口内 |
| CLI-020 | 跨端联动 | Web 加入购物车后打开 H5 | H5 显示同一数据库购物车数量 |
| CLI-021 | 跨端联动 | H5 提交订单后打开 Web | Web 订单中心显示新订单 |
| CLI-022 | 日期 | 查看列表中全部日期时间 | 使用 `YYYY/MM/DD HH:mm` 中文习惯格式 |
