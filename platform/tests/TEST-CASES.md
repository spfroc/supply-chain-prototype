# 供应链平台测试用例

## 测试分层

| 层级 | 文件 | 目标 |
| --- | --- | --- |
| 部署冒烟 | `api-smoke.ps1` | 验证服务入口、健康检查及最短业务主链路 |
| 业务交互 | `interaction-smoke.ps1` | 验证商品、企业、协议、地址、成员的完整增删改链路 |
| 详细回归 | `detailed-regression.ps1` | 分字段验证正常、异常、边界、权限关联与删除约束 |
| 认证回归 | `auth-regression.ps1` | 验证企业选择、注册、登录、当前用户、权限、退出及会话失效 |
| 页面验收 | Playwright CLI | 验证管理后台、Web、H5 页面加载、菜单、弹窗和表单可操作 |

## 详细回归覆盖

| 模块 | 重点用例 |
| --- | --- |
| 权限 | 权限字段完整、编码唯一、未认证访问拒绝 |
| 客户端认证 | 登录无需选择企业、账号登录、手机号登录、注册时输入企业全称、企业名称匹配、注册后自动登录、账号全局识别、默认采购员角色、重新登录、错误密码、退出失效、用户数据隔离 |
| 身份体系隔离 | 后台用户只能登录管理后台、企业成员只能登录 Web/H5、两类账号不能跨端认证 |
| 角色 | 新增角色、配置权限、重复编码、必填校验、关联用户时禁止删除、解除关联后删除 |
| 后台用户 | 新增用户、分配角色、重复账号、必填项、切换角色、停用、删除、超级管理员保护 |
| 基本配置 | 修改后读取验证、Web/H5 公开配置同步、恢复原值、操作日志记录 |
| 门户管理 | 导航、首页轮播图、平台、方案、内容、品牌的新增、编辑、删除及客户端公开数据同步 |
| 平台商品 | 平台与商品多对多关联、平台售价、平台商品链接选填、无链接时隐藏客户端入口、上下架、移除、独立客户端商品列表及首页/列表平台标签 |
| 商品 | 至少十款公开在售商品、新增、主图单图上传、配图最多六张且支持拖拽排序、Web/H5详情图集按后台顺序切换、图片尺寸/比例/大小校验、富文本本地图片/网络图片/网络视频、详情、规格参数、配送说明、售后政策字段持久化、标题必填、负价格、无效分类、编辑、占用库存边界、上下架、删除 |
| 门户图片 | 品牌 Logo 1:1 单图、轮播图 3:1 单图、平台/方案/内容展示图 16:9 单图，前后端校验格式、像素、比例和文件大小 |
| 商品分类 | 一级/二级/三级分类新增、父子级别校验、编辑排序与状态、存在子分类或关联商品时禁止删除 |
| 企业 | 新增、联系人字段、统一信用代码唯一、必填校验、删除、后台按企业管理成员、至少保留一名管理员 |
| 协议 | 新增、同企业唯一生效、旧协议自动失效、协议商品添加、重复添加改价、移除、无效企业 |
| 地址 | 新增、编辑、列表同步、删除、必填校验 |
| 企业成员 | 管理后台按企业查看、新增、设置初始密码、初始密码登录、编辑资料、重置密码、旧密码失效、新密码登录、角色配置、切换角色、停用、删除、重复账号、企业主账号保护 |
| 购物车 | 相同 SKU 合并、数量和勾选修改、删除、零数量、超库存、下架商品不可加入 |
| 游客访问 | Web/H5 首页、分类、商品列表和详情可直接浏览；购物车、订单、用户中心及加入购物车触发登录并在成功后返回原目标 |
| 结算下单 | 立即购买进入确认订单页、购物车提交进入确认订单页、展示默认地址和商品清单、缺少地址禁止提交、线下银行转账提示、成功提交后进入订单列表、下单幂等、空购物车限制 |
| 订单 | 订单列表和详情显示商品封面图、状态筛选、商品明细、金额与数量、不存在订单 |
| 发票 | 发票关联订单、金额有效、第三方开票记录可查询 |

## 执行方法

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\platform\tests\api-smoke.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\platform\tests\interaction-smoke.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\platform\tests\detailed-regression.ps1
```

测试脚本创建的用户、角色、商品、企业、协议、地址和成员均使用时间戳命名，并在用例结束时清理。基本配置测试会恢复原值。
