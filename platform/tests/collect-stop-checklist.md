# 采集任务中止验收

仅在开发环境执行，不操作真实用户正在执行的任务。

- 排队任务：中止后为 CANCELLED，等待项全部 CANCELLED，不调用采集器。
- 执行任务：立即进入 CANCELLING；等待项取消，当前请求成功时保留商品和 SUCCEEDED 条目，之后任务进入 CANCELLED。
- 重试等待：中止后不再发起下一次采集调用。
- 已完成/已中止任务：重复中止不更改已有结果和完成时间。
- 中止中：禁止重试；列表与抽屉继续轮询直到已中止。
- 权限：stop 接口沿用 product:manage 权限，无凭据不得操作。
- 服务重启：中止中的任务恢复为已中止，提醒核对可能已经入库的商品。

中止是安全停止，不是强杀采集器。已发送的 HTTP 请求允许结束，网络超时时应核对入库结果。已中止条目单独计数，不伪装成失败或下架跳过；失败项重试不会恢复已中止条目。
