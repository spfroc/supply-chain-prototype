## 实现覆盖

| 范围 | 处理方式 |
| --- | --- |
| 后台公共初始化、经营概览、基本配置 | 加载态、持久错误说明、重新加载；初始化失败不渲染未就绪页面 |
| 分类树及广告项、楼层内容非分页列表 | 保留完整树/排序列表，不强行分页；失败与空数据区分，支持原位重试 |
| 后台商品、分类属性、企业、平台、协议、品牌、物流、服务、模板等选项 | 共用加载与错误反馈；请求版本防止过期结果覆盖新请求 |
| 用户角色、角色权限、帮助文章选项 | 补充加载失败后的可见反馈和重试 |
| 联系方式、页脚、SEO 配置 | 初始化失败时禁止保存，避免默认值覆盖已有配置 |
| 手工楼层编辑 | 已选内容加载失败时禁止保存，原位重试成功后恢复编辑 |
| 后台分页列表 | 后台刷新错误也可见，成功后清除错误；过期请求不覆盖新状态 |
| Web/H5 公共配置、门户、会话 | 游客与会话异常区分；错误可重试，失败不伪装为空页面；各配置请求独立保留成功数据 |
| Web/H5 方案详情与结算初始化 | 加载、错误、无数据分支；地址/收款账户初始化失败可重试 |

`pagination={false}` 现传递到真实表格。分类树、排序列表和下拉选项所需全量数据不改成分页接口。

## 浏览器回归

使用 Playwright CLI、当前前端构建产物与 comp 真实只读接口；通过浏览器路由注入 503/空数组。没有修改业务记录。桌面视口 1440×1000，H5 390×844。

- Web 门户 503：显示错误与重试；恢复接口并点击重试后首页恢复。
- Web 配置成功、门户失败：网站名称、Logo、联系方式仍使用成功加载的配置，不退回通用占位。
- Web 会话 503：显示初始化错误，恢复后重试正常。
- H5 门户 503：移动端显示可操作错误，恢复后重试正常。
- 后台权限初始化 503：显示错误、重试及返回登录，恢复后可进入。
- 分类树 503：持久错误与重试；恢复后真实分类出现。
- 分类树 200 空数组：显示“暂无数据”，不显示请求错误。
- 联系方式 503：显示错误、保存禁用；重试成功后恢复。
- 广告项弹窗 503：错误与重试；恢复后真实广告项出现，无分页控件。
- 商品分页列表 503：错误可见；恢复后重试，错误文本消失。

其他表单选项、手工楼层编辑、方案与结算分支完成代码覆盖及 TypeScript 构建检查；本轮未逐个页面做人工业务保存验收。系统配置菜单未使用越权方式测试。
