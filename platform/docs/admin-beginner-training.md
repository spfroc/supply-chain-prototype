# 政企采购供应链 · 管理后台新手培训教程

适用对象：首次使用「供应链运营中心」的运营、财务、系统管理员。  
培训目标：独立完成登录、找菜单、维护商品/企业/协议、处理订单、配置门户，并知道什么操作会直接影响 Web / H5 客户端。

访问地址（按环境二选一）：

| 环境 | 管理后台 | 企业采购端 |
| --- | --- | --- |
| 本机 Docker | http://localhost:18088/admin/ | Web：`/web/` · H5：`/h5/` |
| 服务器 | http://supply.comp/admin/ 或 http://182.168.1.114:18088/admin/ | 同主机的 `/web/`、`/h5/` |

---

## 1. 先建立一张业务地图

管理后台不是「改网站文案的 CMS」，而是整条政企采购链路的运营中枢。客户端（电脑端 Web、手机端 H5）下的每一笔采购，都依赖后台先把基础数据准备好。

推荐记住这一条主链路：

```
分类 / 品牌 / 属性  →  商品上架
企业建档 / 成员开通  →  签订协议  →  协议商品定价
企业在 Web/H5 下单  →  后台确认到账  →  填写物流  →  完成订单
```

另外三条「旁路」不要和主链路搞混：

- **平台**：把自营商品挂到第三方采购平台（国网、军采等），展示平台价和跳转链接。
- **方案**：把若干 SKU 打包成采购场景（必选 / 可选、默认数量）。
- **门户**：只改首页、导航、页脚、SEO，不改订单和库存。

## 2. 登录（第一课，必须过关）

1. 用浏览器打开管理后台地址，看到「供应链运营中心 / 管理后台登录」。
2. 输入 **后台账号或手机号** + **登录密码**，回车或点「登录管理后台」。
3. 登录成功后，左上角品牌区显示「供应链运营中心」，右上角显示你的姓名和角色。

### 开发环境演示账号（仅培训/联调用）

这些账号来自数据库初始化脚本，**上线前必须改密或停用**。

| 账号 | 默认密码 | 角色 | 能做什么 |
| --- | --- | --- | --- |
| `admin` 或手机 `13800000001` | `change-me-before-production` | 超级管理员 | 全部菜单 |
| `operator` 或 `13800000002` | `demo-password` | 运营管理员 | 概览、商品、企业、协议、订单 |
| `finance` 或 `13800000003` | `demo-password` | 财务人员 | 概览、订单、操作日志 |

### 新手最容易踩的坑

- **企业采购员不能登录管理后台。** 页面底部写得很清楚：企业成员请走 Web / H5。后台账号和企业账号是两套体系。
- **连续输错会被锁定 15 分钟**，接口返回「登录尝试过多」。不要用脚本或多人共用同一账号反复试密。
- 登录凭证只保存在当前浏览器标签的会话里（关闭标签需重新登录），不要把密码发给同事或写进公开文档。
- 右上角点「退出」才会真正登出。

## 3. 界面导览：十分钟认路

登录后屏幕分成四块：

| 区域 | 你能做什么 |
| --- | --- |
| 左侧菜单 | 按业务分组进入页面。没有权限的菜单会自动隐藏。 |
| 顶部标题 | 显示当前模块名称。 |
| 顶部搜索框 | 按**页面名称**跳转（例如输入「订单」「协议」），不是搜某一笔真实订单。 |
| 顶部右侧 | 服务健康（API / 数据库是否正常）、当前账号、退出。 |
| 内容区 | 当前模块的列表、表单、按钮。右上角有「刷新数据」。 |

### 左侧菜单一览

1. **经营概览** — 后台用户数、角色数、权限点数、今日操作次数。
2. **商品管理** — 商品、分类、品牌、属性模板。
3. **订单管理** — 全部采购订单。
4. **平台管理** — 第三方平台、平台商品、含平台商品的订单。
5. **协议管理** — 企业协议、协议商品、协议订单。
6. **方案管理** — 采购方案、方案商品。
7. **企业管理** — 企业客户、全部企业用户。
8. **门户管理** — 导航、轮播、楼层、广告、内容、联系方式、服务保障、页脚、SEO。
9. **系统管理** — 后台用户、角色、权限、操作日志、基本配置。

默认展开「商品管理」和「订单管理」。点分组名称可折叠。

## 4. 所有列表页的共同用法（学会一次，处处通用）

几乎每个模块都是同一套表格工具栏：

1. **搜索框**：输入名称、编码、手机、订单号等关键字，回车或点搜索。
2. **状态筛选**：如「在售 / 草稿 / 已下架」「待付款 / 待发货」等，可清空回到全部。
3. **勾选行**：左侧复选框。底部显示「已选 N 项」。
4. **批量导出选中**：把勾选行导出为 CSV（Excel 可打开）。导出的是当前列表字段，不是报表。
5. **清空选择**：取消勾选。
6. **分页**：每页 10 / 20 / 50 / 100 条，可跳页。底部「共 N 条」。
7. **危险操作都有确认框**：删除、完成订单、移除关联前会再问一次。点错就取消。

状态颜色约定（多数页面一致）：

- 绿色标签 = 启用 / 在售 / 已确认 / 已完成
- 蓝色标签 = 进行中、自营、协议/平台名称
- 橙色标签 = 待审核、低库存、待确认付款
- 灰色 / 默认 = 停用、下架、草稿、已取消

## 5. 角色、权限与「为什么我看不见这个菜单」

权限由「角色」打包，再赋给「后台用户」。你登录后，系统按权限码过滤左侧菜单。

| 权限码 | 权限名称 | 打开哪些菜单 |
| --- | --- | --- |
| `dashboard:view` | 查看经营概览 | 经营概览 |
| `product:manage` | 管理商品 | 商品、分类、品牌、属性、平台、方案、门户全部页面 |
| `enterprise:manage` | 管理企业 | 企业、企业用户 |
| `agreement:manage` | 管理协议 | 协议、协议商品 |
| `order:manage` | 管理订单 | 订单、协议订单、平台订单 |
| `system:user` | 管理后台用户 | 系统 → 用户管理 |
| `system:role` | 管理角色权限 | 角色管理、权限管理 |
| `system:config` | 管理基础配置 | 基本配置 |
| `system:log` | 查看操作日志 | 操作日志 |

内置三种岗位（可在「角色管理」改，但培训期建议先用默认）：

| 角色 | 典型岗位 | 建议培训重点 |
| --- | --- | --- |
| 超级管理员 | 系统负责人 | 全教程；重点学会给别人开账号、改配置 |
| 运营管理员 | 商品/客户运营 | 第 6～10 课：商品、企业、协议、订单、门户 |
| 财务人员 | 出纳 / 财务 | 第 3、4、10 课：界面、订单确认到账与退款、日志 |

权限点在「权限管理」里只能查看，**不能在页面上新增或删除**（由系统注册，防止误删）。

## 6. 推荐学习路径（按岗位）

### 6.1 所有人（约 30 分钟）

1. 登录、认界面、看经营概览和服务健康灯。
2. 用顶部搜索跳到「订单管理」「商品管理」试一次。
3. 打开任意列表：搜索、筛选、勾选、导出、清空。
4. 打开「操作日志」看别人刚做过什么（只读）。

### 6.2 运营（约半天，跟练）

按下面顺序实操，不要跳：

1. 分类管理：建好三级分类  
2. 品牌管理：新建一个品牌并启用  
3. （可选）属性模板：给该分类加 1～2 个属性  
4. 商品管理：新建商品（先草稿，确认无误再上架）  
5. 企业管理：新建企业 → 添加企业管理员  
6. 协议管理：给该企业签一份生效协议 → 加入刚才的商品并定价  
7. 让同事用 Web/H5 登录企业账号，确认能看到协议价  
8. 门户：改一张轮播图，刷新 Web 首页验收

### 6.3 财务（约 1 小时）

1. 订单管理：用状态筛选「待付款」  
2. 打开订单详情，核对金额、企业、采购人  
3. 确认银行到账后点「确认到账」  
4. 已完成订单如需退款，点「退款」并填写金额与原因  
5. 到操作日志核对刚才的动作是否记成功

### 6.4 系统管理员（约 1 小时）

1. 用户管理：为新同事开账号、分配角色、设初始密码（至少 8 位）  
2. 角色管理：理解三个默认角色，不要随便删超级管理员  
3. 基本配置：看懂平台名称、付款时限、低库存阈值；改前先记原值  
4. 收款银行：核对对公账户，错账会导致企业无法正确转账

## 7. 商品中心

### 7.1 分类管理

客户端按 **三级分类** 浏览商品。新建商品时，下拉框里只出现「已启用的三级分类」。

操作建议：

1. 先建一级（例如「办公设备」），再在其下建二级，再在二级下建三级。
2. 填写名称、排序、状态。数字越小越靠前。
3. **有子分类或已挂商品时不能删除**，应先停用或把商品改到别的分类。
4. 停用分类不会立刻删商品，但前台可能不再按该分类露出。

### 7.2 品牌管理

商品必须选择一个 **已启用品牌**。字段：名称、说明、Logo（1:1，300～2000 像素，最大 2MB）、排序、状态。

### 7.3 属性模板

给某个分类（或全局）定义「内存容量、颜色」这类字段，发布商品时自动出现在「规格属性」页签。

关键选项：

| 字段 | 含义 |
| --- | --- |
| 属性用途 | 基础属性 / 销售规格 / 扩展属性 |
| 输入组件 | 文本、数字、下拉、单选、多选、开关、日期 |
| 适用范围 | 全局通用（所有分类）或指定分类（上级分类会继承到下级） |
| 必填 / 前台展示 / 参与筛选 / 参与搜索 | 控制客户端表现 |
| 选项 | 下拉/单选/多选时必须先维护选项名称和编码 |

分类还没配模板时，商品表单会提示「当前分类尚未配置属性模板」，可以先空着，不影响上架。

### 7.4 商品管理（核心课）

点「＋ 新增商品」，弹窗有四个页签，建议按顺序填完再保存：

**① 基本信息**

- 分类：必须选三级
- 品牌、型号、是否自营
- 商品标题（必填）
- 主图（必填）：1:1，600～3000 像素，最大 5MB
- 轮播图：最多 6 张，可拖动排序

**② 规格与 SKU**

- 每个 SKU 是一个可独立卖的规格（颜色、容量等）
- 销售规格写法：`规格=标准` 或 `颜色=黑色；容量=256GB`
- SKU 标题默认 = 商品标题 + 销售规格，可改
- 市场价、会员价、库存必填；SKU 编码留空则系统生成
- 至少保留 1 个 SKU；多规格点「添加 SKU」
- 默认库存数量在「系统管理 → 基本配置 → 库存配置」

**③ 规格属性**

- 内容随所选三级分类变化；标了「继承自上级分类」的不用重复建

**④ 详情与服务**

- 商品服务（新建时默认全选，选项在基本配置里维护）
- 摘要、富文本详情
- 配送说明模板、售后政策模板（在基本配置里维护模板后再选）

保存后商品一般是 **草稿**。列表操作：

| 按钮 | 作用 |
| --- | --- |
| 编辑 | 改四个页签 |
| 库存 | 仅单 SKU 商品可在此改总库存；多 SKU 请展开行或进编辑 |
| 平台 | 把某个 SKU 挂到采购平台并填平台价 |
| 协议 | 把商品加入一个或多个生效协议（新增关联默认用会员价，已有协议价不会被覆盖） |
| 上架 / 下架 | 在售 ↔ 下架。草稿需上架后客户端才买得到 |
| 双击「商品角标」 | 快速改角标：自动 / 协议专属 / 指定平台 / 自定义（2～5 个汉字） |

列表还可按分类、品牌、自营、库存区间、角标筛选。勾选后支持：批量上架、批量下架、设为自营/非自营、批量改库存（会把所选商品的全部 SKU 设成同一库存，且不能低于已占用库存）。

展开多 SKU 行可以看到每个规格的价格、可售/总库存、占用库存，以及启用/停用该 SKU。

**可售库存 = 总库存 − 已占用库存。** 企业下单会占用库存，不要把总库存改得比占用还小。

## 8. 企业与账号（两套用户，别混）

### 8.1 企业管理

维护采购方客户：

- 必填：企业名称、统一社会信用代码（全局唯一）、联系人、联系电话
- 选填：企业地址
- 状态：正常 / 停用（停用后该企业一般无法继续正常采购）

行内「成员管理」可在该企业下添加采购员 / 企业管理员。每个企业至少保留一名管理员，删除会失败。

### 8.2 企业用户管理（菜单名也叫「用户管理」，在「企业管理」分组下）

这是 **Web/H5 登录账号**，不是后台账号。

| 字段 | 规则 |
| --- | --- |
| 所属企业 | 新建后不可改 |
| 登录账号 | 3～80 位，创建后不可改 |
| 初始密码 | 8～72 位；编辑时留空表示不改密 |
| 姓名、11 位手机号 | 必填 |
| 企业角色 | 采购员 / 企业管理员 |
| 账号状态 | 待审核(2) / 已启用(1) / 已停用或未通过(0) |

企业自己在客户端注册后，状态常常是「待审核」。运营在此把状态改为「审核通过 / 启用」，对方才能下单。

重置密码后，旧密码立即失效。把新密码通过安全渠道发给对方，不要发到公开群。

## 9. 协议：企业专属价格

同一企业 **同时只能有一份生效协议**。新建并设为「生效中」时，旧协议会自动失效。

新建协议字段：

- 签约企业、协议名称、协议金额
- 状态：生效中 / 待生效 / 停用
- 生效日期、到期日期

然后必须做第二步：**商品管理**（行内按钮，或左侧「协议商品管理」）：

1. 「添加现有商品」，选已上架 SKU
2. 填写 **协议价**（企业实际成交价）
3. 保存。重复添加同一 SKU 等于改价，不会产生两行
4. 「移除」是软删除，不会删除商品库里的商品

客户端展示价格优先级（培训只需记住）：有生效协议且该 SKU 在协议内 → 显示协议价；否则显示会员价/市场价。角标选「协议专属」时，只有命中协议价的企业才看得到该角标。

「协议订单管理」= 订单列表的过滤视图，只显示协议产生的订单，履约操作与总订单相同。

## 10. 订单履约（财务 + 运营都要会）

订单由企业在 Web/H5 提交，**后台不能手工新建订单**。后台负责查单、确认收款、发货、完成、退款。

### 10.1 列表里能看到什么

卡片式一行一单：商品明细、应付金额（商品金额 + 运费）、买方企业/采购人/电话、订单状态、付款状态、是否协议单。

状态筛选：

| 订单状态 | 含义 | 后台接下来做什么 |
| --- | --- | --- |
| 待付款 | 已下单，钱未确认 | 核对银行到账后点「确认到账」 |
| 待发货 | 已收款，货未出 | 进详情给每个商品填物流 |
| 部分发货 | 部分商品已发 | 继续填其余商品物流 |
| 运输中 | 在途 | 等签收或点「确认完成」 |
| 已完成 | 全部签收 | 必要时退款 |
| 已取消 | 超时未付或整单取消 | 只读 |

付款状态：待付款 → 待确认 → 已确认。  
退款状态：未退款 / 已退款。

### 10.2 标准履约步骤

1. 搜索订单号或企业名称，打开 **订单详情**。
2. 核对：订单号、企业、采购人、电话、协议、金额、付款截止时间、配送地址（同一地址会合并显示「同址配送」）。
3. 银行到账无误后，在列表点 **确认到账**（待付款单）。订单变为待发货。
4. 在详情每件商品点 **物流**：发货状态、物流公司、运单号、物流说明。保存后订单状态会按全部商品自动汇总（待发货 / 部分发货 / 运输中 / 已完成）。
5. 货已签收，点 **确认完成**。系统会把已发货/运输中的商品同步为已签收。
6. 仅已完成且未退款的订单可以 **退款**：填退款金额和原因。这是后台记账，不自动打款到银行卡。

发货状态允许的流转：待发货 → 已发货或运输中或已取消；已发货 → 运输中或已签收；运输中 → 已签收。不能倒退。

详情底部有 **订单操作时间线**，可区分「客户端」还是「管理后台」做的操作。

「平台订单管理」只列出包含平台关联商品的订单，操作相同。

## 11. 平台与方案

### 11.1 平台管理

维护第三方采购渠道：名称、说明、跳转链接、**价格显示前缀**（如填「国网」，前台显示「国网价」）、展示图、排序、启停。

每条平台有系统内部链接：`/web/platforms/{id}/products`，可复制给门户导航使用。

在平台行点「商品管理」，或使用「平台商品管理」页：选择平台 + SKU + 平台售价 + 可选商品链接 + 上架/下架。支持批量上架、下架、移除。

### 11.2 方案管理

维护「会议室改造」「值班室设备」这类场景包：名称、适用场景、方案说明、Web 16:9 海报（必填），H5 还可配 9:16 竖版海报。

方案商品字段与协议不同：

- 默认数量
- 必选商品 / 可选商品
- 排序

没有单独的「方案价」字段，价格仍走商品会员价或协议价。

## 13. 系统管理

### 13.1 后台用户（系统分组下的「用户管理」）

与「企业用户」不是同一页。字段：登录账号、姓名、手机、邮箱、初始密码（新建至少 8 位；编辑留空不改密）、启用/停用、分配角色（可多选）。

**超级管理员（id=1）不能删除。** 停用账号后对方无法登录。

### 13.2 角色管理

填写角色名称、编码（如 `CONTENT_EDITOR`）、说明，勾选权限。  
仍有用户使用的角色不能删除；超级管理员角色不能删除。

### 13.3 操作日志

只读。记录模块、动作、对象、操作人、IP、成功/失败。出了问题先在这里查「是谁改的」。

### 13.4 基本配置

按分组展示，改完即时保存：

- **平台信息**：名称、Logo、英文名、口号等，影响 Web/H5 页头
- **订单配置**：银行转账付款时限（小时）、超时是否自动取消
- **库存配置**：低库存阈值、新建 SKU 默认库存
- **商品服务 / 配送模板 / 售后政策模板**：供商品表单勾选
- **收款银行**：对公户名、开户行、账号、网点；企业付款页展示已启用账户
- **选项管理**：如物流公司列表，发货弹窗会用到

联系方式、页脚、SEO 不在本页，请到「门户管理」对应菜单，避免改两处。

## 17. 常见问题

**Q：登录提示账号或密码错误，但密码明明对。**  
A：确认走的是 `/admin/` 不是 `/web/`；账号被停用也会失败；手机号登录时不要加空格。试 5 次以上可能被锁 15 分钟。

**Q：菜单比同事少。**  
A：角色权限不同。找超级管理员在「用户管理」核对角色，或临时用有权限账号演示（不要借用生产超管密码）。

**Q：商品保存了，客户端看不到。**  
A：检查：商品是否「在售」、SKU 是否启用、分类/品牌是否启用、企业是否有协议（部分楼层只展示协议商品）、库存是否为 0。

**Q：为什么不能删这个分类/角色/用户？**  
A：分类下有子类或商品；角色仍绑着用户；超级管理员账号/角色受保护；企业至少留一名管理员。

**Q：确认到账按钮点了没反应。**  
A：只有订单状态为「待付款」才显示「确认到账」。已确认过的不会再出这个按钮。看详情时间线是否已有记录。

**Q：顶部搜索搜不到某张订单。**  
A：顶部框只跳转菜单。请进入「订单管理」，用列表搜索框搜订单号。

**Q：改了配置，前台没变。**  
A：硬刷新浏览器；检查是否改错端（Web 与 H5 楼层/广告可分开）；状态是否停用；广告是否在生效时间窗外。

**Q：协议商品「移除」后，商品库里的商品没了吗？**  
A：没有。只是从该协议里拿掉，商品管理里还在。

## 18. 操作纪律（培训结束必须记住）

1. 生产环境不要用文档里的演示密码。
2. 调价、改库存、确认到账、退款属于资金相关操作，做前先看清企业和金额。
3. 删除、停用、下架前先搜索是否仍被协议、方案、楼层引用。
4. 不确定就先在列表导出或看操作日志，而不是反复点删除。
5. 企业用户密码、后台密码只通过内部安全渠道传递。

讲师验收建议：学员能独立走完「建分类 → 上架商品 → 建企业与协议 → 解释一笔订单下一步该做什么」，即可视为通过新手培训。
