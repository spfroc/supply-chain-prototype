# 样板与正式版功能差异清单

更新时间：2026年7月29日

## 本轮已补齐

- 管理后台独立的三级商品分类管理：新增、编辑、排序、启停、删除。
- 分类父子级别校验；存在子分类或关联商品时禁止删除。
- 商品资料增加主图、配图、属性和富文本详情字段。
- 商品新增、编辑和列表接口持久化完整商品资料。
- Web 商品卡片优先展示后台配置的主图。

## 正式版仍缺失或不完整

### 高优先级

- 首页导航栏管理及 Web/H5 动态导航联动。
- 首页轮播图管理、投放终端、排序和上下线。
- 方案管理：方案资料、方案商品、方案详情和整套加入购物车。
- 平台管理：平台资料、商品关联、平台售价、商品链接、上下架和点击量。
- 结算页多地址按 SKU 拆分数量、分配校验和订单地址明细。
- 商品图片上传到阿里云 OSS，目前商品表单先支持填写 OSS 地址。

### 中优先级

- 品牌管理和规格模板管理。
- 订单银行转账记录、到账凭证、确认到账和操作记录。
- 发货信息、物流单号、快递100轨迹查询和异常提示。
- 发票后台状态流转、第三方发票号码和附件记录。
- 内容/文章管理以及客户端帮助内容。

### 细节优化

- Web/H5 分类筛选改为完全读取后台三级分类。
- 商品详情的配图切换、属性分组和安全富文本渲染。
- 列表搜索、筛选、分页、空状态和批量操作统一。
- 表单离开提醒、重复提交保护、敏感操作二次确认。
- 操作日志补充业务管理模块的新增、编辑、删除和状态变更。
